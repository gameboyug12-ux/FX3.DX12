# FX3.DX12 0.3.7 — Native Qt editor and DXR viewport

## Application split

Version 0.3.7 adds a separate native Windows application, `FX3Editor.exe`.
It is a Qt 6 Widgets application and does not replace or embed itself in
`main.exe`. The engine executable remains a separate target.

## Editor layout

- Central native Win32 viewport hosted by a Qt widget.
- Scene Outliner dock.
- Properties dock with transform fields.
- Console dock and fullscreen shortcut (F11).

## DXR viewport

The viewport creates its own D3D12 device and command queue, checks
`D3D12_FEATURE_D3D12_OPTIONS5`, and refuses to silently present a raster
fallback when DXR is unsupported. It creates a triangle BLAS and a TLAS,
creates a DXR state object and shader binding table, dispatches rays into an
RGBA8 UAV texture, copies that texture to the DXGI swap-chain backbuffer, and
presents it.

This is a real single-bounce DXR validation renderer. It is not yet a general
Blender replacement or a production path tracer. Scene editing, model import,
camera controls, materials, multi-bounce lighting, accumulation, denoising,
and a full render graph remain future work.

## Build requirements

- Windows 10/11 x64 with a DXR-capable GPU and current graphics driver.
- Visual Studio 2022 with C++ desktop workload and Windows 10/11 SDK.
- CMake 3.24 or newer.
- DirectX Shader Compiler (`dxc.exe`) available on PATH.
- Qt 6 Widgets development package discoverable by CMake.

Configure and build:

```powershell
cmake -S . -B build -A x64 -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/msvc2022_64"
cmake --build build --config Release
```

The editor is emitted as `build/bin/FX3Editor.exe`. The engine executable and
DLL remain separate outputs.

## Current limitations

The DXR viewport uses a hard-coded triangle scene to validate the hardware
pipeline. The transform controls and Outliner are editor UI foundations and
are not yet connected to dynamic BLAS/TLAS rebuilds. No claim of Windows
compilation or runtime verification is made until the project is built and
run on a DXR-capable Windows system.
