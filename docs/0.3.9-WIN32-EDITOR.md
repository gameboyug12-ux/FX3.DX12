# FX3 Editor 0.3.9 — Native Win32

The standalone editor target is now implemented with the Windows API and C++20.
It no longer uses Qt6 or requires Qt development packages.

## Native editor features
- Standard resizable Windows top-level window and system title bar.
- Native File / Scene / Help menus and a compact toolbar.
- Scene Outliner backed by the Win32 TreeView common control.
- Properties panel with object name/type and nine transform fields.
- Console output panel and native status bar.
- New, open, save, save-as, add-triangle, delete and unsaved-change prompts.
- `.fx3scene` JSON version 1 read/write support, preserving the existing format.
- DXR viewport hosted by a child HWND and rendered by the existing D3D12/DXR renderer.

The renderer still uses its existing fixed test triangle. This editor migration does not
claim scene-driven BLAS/TLAS updates or a completed 16-bounce path tracer; those are
separate renderer milestones.

## Build
Requires Windows 10/11 SDK, CMake 3.24+, MSVC C++20 and DXC on PATH.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --target FX3Editor
```

The editor executable is written to `build/bin/FX3Editor.exe` (the project retains its
existing output name).
