# FX3.DX12 0.3.1 — Editor prototype

This milestone adds a separate PySide6 editor application with Scene and Inspector panels, an OpenGL OBJ viewport, output log, AA / FSR / path tracing controls, and engine process launch (F5).

The OBJ preview is currently rendered by the editor's OpenGL viewport. It is not the native D3D12 renderer. DXR, progressive path tracing and FSR 3 are not implemented in this prototype; their controls are placeholders and are labeled as such.

## Run on Windows

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r editor\requirements.txt
python editor\main.py
```

The default executable path is `C:/XWe0.2/bulid/main.exe`. Change it using File > Set engine executable.
