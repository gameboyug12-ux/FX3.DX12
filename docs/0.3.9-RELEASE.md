# FX3.DX12 0.3.9 — Release integration

## Build products

The CMake build can produce both engine variants:
- `out/dynamic/xwe_engine.dll` and its import library
- `out/static/xwe_engine.lib`
- `out/main.exe`
- `out/editors/FX3Editor.exe` (native Win32 scene editor)
- `out/shaders/` (raster, legacy DXR preview and hybrid DXR libraries)

The runtime and editor copy the shared engine DLL beside their executables when
`FX3_LINK_ENGINE=DYNAMIC`. Use `-DFX3_LINK_ENGINE=STATIC` for static linking.

## Editor

The primary editor is `editor/win32`: native menus and toolbar, scene outliner,
object name/type and transform properties, console, status bar, scene new/open/save,
add/delete operations, dirty-state prompts, versioned `.fx3scene` serialization and
the D3D12 viewport. The separate 0.4 editor suite in the uploaded source package is
a UI prototype; it is not presented as a replacement for the scene editor.

The viewport still uses its built-in preview geometry. The release does not claim that
arbitrary scene-document objects are automatically converted into BLAS/TLAS instances.

## Hybrid DXR path tracing

`DX12RaytracingApi` creates a global root signature for the hybrid shader's five-entry
SRV table and one-entry UAV table. `hybrid_pathtrace.hlsl` provides:
- up to three sequential path bounces
- direct lighting with secondary visibility/shadow rays
- rough and metallic reflection sampling
- cosine-weighted diffuse indirect illumination
- four spatial samples per pixel

The host supplies scene descriptors and buffers according to
`RT_DESCRIPTOR_LAYOUT.md`. The old `DxrPipeline` and `pathtrace.hlsl` remain
available for the editor's legacy DXR preview. Temporal accumulation, denoising,
automatic scene-to-AS building and render-graph integration remain future work.

## Verification

Requires Windows 10/11 SDK, MSVC C++20, CMake 3.24+ and DXC with Shader Model 6.3 /
DXR library support.

```powershell
cmake -S . -B build-fx3 -A x64 -DDXC_EXECUTABLE="C:/XWe0.2/cmp-utils/dx/dxc.exe"
cmake --build build-fx3 --config Release --target XWeShaders xwe_engine_shared xwe_engine_static FX3DX12 FX3Editor
```

CMake generation and source/layout checks were performed before commit. DXC shader
compilation, MSVC compilation, DXR state-object creation and GPU rendering require
verification on Windows with a DXR-capable adapter; they are not claimed as completed
by this commit.
