# FX3.DX12 0.3.4 — XWe Java API specification

## Based on
This release continues from the existing `release/0.3.3` commits. It preserves
the DX12/DXR feature detection, DXR state-object foundation, raster PSO cache,
XWe application DLL, and editor work.

## Added
- `src/xwe/java/api/java.txt`: Java-facing API specification.
- Java 22+ Foreign Function & Memory API (Panama) is the planned interop path.
- The contract maps Java application lifecycle operations to the existing
  exports in `include/XWeApplication.h`.
- CMake project version and `XWeGetVersion()` now report `0.3.4`.

## Java API scope
The specification defines `XWeApplicationDesc`, `XWeApplication`,
`XWeVersion`, and `XWeException`, plus lifecycle, native-memory ownership,
UTF-16 string handling, and error behavior.

## Important implementation status
This milestone adds the API contract only. It does not yet add Java source
classes, Panama downcall bindings, JNI wrappers, Gradle/Maven configuration,
or Java integration tests. Do not treat the Java API as executable yet.

The native engine remains C++20 and Direct3D 12. Java is intended to be an
optional host/application layer over the stable C ABI, not a replacement for
the renderer.

## Native build
```powershell
cmake -S . -B build -A x64
cmake --build build --config Debug
```

Requires the Windows SDK and DXC as documented by the 0.3.3 DXR milestone.
