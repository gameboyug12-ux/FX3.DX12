# FX3.DX12 0.3.3 — DX12 Ultimate, DXR and PSO foundation

## Added
- Runtime feature probing: DXR (OPTIONS5), mesh shaders and sampler feedback (OPTIONS7), enhanced barriers (OPTIONS12), and variable-rate shading (OPTIONS6).
- A keyed graphics PSO cache. Callers supply a stable key and must change it whenever any PSO-defining state changes.
- A DXR shader library with ray-generation, miss and closest-hit exports, compiled as lib_6_3.\n- Native DXR raytracing state-object creation through ID3D12Device5 on DXR-capable adapters.
- Raster fallback remains available when DXR is unsupported.

## Scope boundary
This is a DXR/path-tracing foundation, not a completed path tracer. On a DXR-capable adapter the engine now creates a native raytracing pipeline state object from the compiled shader library. It does not yet build BLAS/TLAS acceleration structures, a shader binding table, a raytracing output UAV, call DispatchRays, accumulate samples, denoise, or composite a raytraced image. The visible cube remains rasterized.

DX12 Ultimate is a collection of optional hardware/driver features, not one universal switch. Query the actual adapter; a GPU name alone does not prove support.

## PSO cache
GraphicsPsoCache::GetOrCreate(device, stable_key, desc) stores and reuses graphics pipeline states by caller-provided key. Keys are not derived from descriptors. Never reuse a key for different shaders, root signatures, formats, blend, rasterizer, depth/stencil or sample state.

## Build
Requires Windows 10/11 SDK headers and libraries plus DXC supporting lib_6_3.
```powershell
cmake -S . -B build -A x64
cmake --build build --config Debug
```
