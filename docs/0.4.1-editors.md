# FX3.DX12 0.4.1 — Editor applications

This branch adds two separate editor front ends. They edit the same versioned
`FX3Scene` v1 JSON document format. Neither editor modifies the root
`CMakeLists.txt`; the Win32 editor is built with its own script and
the Tkinter editor runs directly with Python.

## Native Win32 editor

Source: `editor/win32/`

- Native Win32 window, menu, toolbar, TreeView Outliner, inspector, console and status bar.
- New/Open/Save/Save As for .fx3scene` files, including unsaved-change prompts.
- Add/delete scene objects, select objects, edit names and all nine transform values.
- DirectX 12 / DXR viewport host with a hardware ray-tracing validation triangle.
- Requires Windows 10/11 x64, Visual Studio 2022 C++ tools, Windows SDK, DXC and a DXR-capable GPU.

Build from a Visual Studio Developer PowerShell at repository root:

```powershell
.\editor\win32\build_win32_editor.ps1
```

Executable: `out/editor/FX3Win32Editor.exe`. The shader is compiled
to `out/editor/shaders/pathtrace.dxil` by the script.

## Tkinter scene and asset editor

Source: `editor/tkinter/fx3_editor.py`

Run on Python 3.10+:

```powershell
py -3 editor/tkinter/fx3_editor.py
```

Or double-click `editor/tkinter/run_editor.bat`.

Implemented workflows:

- Create, open, save and save-as scene documents with schema validation and atomic replacement.
- Scene Outliner with object selection, object creation and deletion.
- Inspector edits names, position, rotation and scale.
- Material inspector edits base color, metallic and roughness values.
- Texture references can be assigned or cleared.
- Wavefront OBJ import validates vertices/faces and adds the mesh asset reference to the scene.
- Console reports editor actions and file operations.

## Scope and honest limitations

The Tkinter viewport is a scene-document preview, not a live Direct3D viewport.
OBJ import currently validates the file and stores its path/reference; it does
not upload mesh geometry to the GPU. Texture assignment stores an asset path;
it does not decode or preview texture pixels. The native Win32 DXR viewport is
still the hardware test-triangle renderer and is not yet bound to editable
scene objects. Scene document edits are real and persist, but live scene
rendering, GPU mesh upload, material shader binding, camera navigation,
undo/redo and a full asset pipeline remain future work.

The release is not represented as a production-ready full game editor. The
source has not been compiled or runtime-tested on Windows in this environment.
